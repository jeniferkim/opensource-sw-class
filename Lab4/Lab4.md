# Lab 4 - Shell Commands

## 1. Linux와 Shell

Linux는 오픈소스 Unix 계열 운영체제이며, 오픈소스 소프트웨어 개발에 널리 사용된다.

운영체제는 크게 Kernel과 Shell을 통해 사용자와 하드웨어 사이에서 동작한다.

- **Kernel**: 운영체제의 핵심 부분으로 하드웨어 자원을 제어하고 통신한다.
- **Shell**: 사용자가 Kernel과 명령어를 통해 통신할 수 있도록 해주는 인터페이스이다.
  - 예: `bash`, `zsh`

사용자는 Shell을 통해 프로그램을 실행하거나 명령어를 입력한다.

---

## 2. CLI와 GUI

### CLI (Command Line Interface)

명령어를 직접 입력하여 컴퓨터를 사용하는 방식이다.

특징:

- 명령어를 기억해야 한다.
- 주로 키보드를 사용한다.
- 비교적 빠르다.
- Script를 이용해 반복 작업을 자동화할 수 있다.
- 개발자가 주로 사용하는 기본적인 환경이다.

### GUI (Graphical User Interface)

아이콘이나 화면을 클릭하여 컴퓨터를 사용하는 방식이다.

특징:

- 직관적이고 사용하기 쉽다.
- 주로 마우스를 사용한다.
- 반복 작업을 직접 수행해야 하는 경우가 많다.

# Shell Commands

## 3. `pwd`

`pwd`는 현재 작업하고 있는 디렉토리의 경로를 확인하는 명령어이다.

```bash
pwd
```

예시:

```bash
/Users/user
```

현재 터미널에서 내가 어느 디렉토리에 위치하고 있는지 확인할 때 사용한다.

---

## 4. `ls`

`ls`는 현재 디렉토리에 존재하는 파일과 디렉토리 목록을 확인하는 명령어이다.

```bash
ls
```

### 주요 옵션

#### `-l`

파일과 디렉토리의 상세 정보를 출력한다.

```bash
ls -l
```

Long Format에서는 다음과 같은 정보를 확인할 수 있다.

- 파일 권한
- 소유자
- 그룹
- 파일 크기
- 수정 시간
- 파일 이름

#### `-lh`

`-l`과 동일하게 상세 정보를 보여주지만 파일 크기를 읽기 쉬운 단위로 표시한다.

```bash
ls -lh
```

---

## 5. `cd`

`cd`는 현재 작업 중인 디렉토리를 변경하는 명령어이다.

```bash
cd directory_name
```

예시:

```bash
cd folder1
```

### 경로 표현

| 표현 | 의미                         |
| ---- | ---------------------------- |
| `/`  | root directory               |
| `.`  | 현재 디렉토리                |
| `..` | 상위 디렉토리                |
| `~`  | 현재 사용자의 home directory |

### 절대 경로

Root directory부터 전체 경로를 지정하는 방식이다.

```bash
cd /directory_name
```

### 상대 경로

현재 위치를 기준으로 이동하는 방식이다.

```bash
cd ./directory_name
```

또는

```bash
cd ../directory_name
```

---

## 6. 자동완성

Shell에서는 `Tab` 키를 이용하여 명령어나 디렉토리 이름을 자동완성할 수 있다.

예를 들어 다음과 같이 입력한 뒤:

```bash
cd f
```

`Tab` 키를 누르면 해당 이름과 일치하는 디렉토리 이름을 자동으로 완성할 수 있다.

긴 파일 이름이나 디렉토리 이름을 입력할 때 유용하다.

---

## 7. 이전 명령어 불러오기

키보드의 `↑` 방향키를 누르면 이전에 사용했던 명령어를 다시 불러올 수 있다.

같은 명령어를 반복해서 사용할 때 다시 입력하지 않아도 되기 때문에 편리하다.

---

## 8. `clear`

`clear`는 터미널 화면을 정리하는 명령어이다.

```bash
clear
```

실행하면 이전에 화면에 출력된 명령어와 결과가 보이지 않게 되어 터미널 화면을 깔끔하게 사용할 수 있다.

---

# File & Directory Manipulation

파일과 디렉토리를 조작하는 명령어는 기존 파일을 삭제하거나 덮어쓸 수 있으므로 주의해야 한다.

중요한 파일은 작업 전에 백업하는 것이 좋다.

---

## 9. `cp`

`cp`는 파일이나 디렉토리를 복사하는 명령어이다.

### 파일 복사

```bash
cp file1 file2
```

`file1`의 내용을 `file2`로 복사한다.

`file2`가 존재하지 않으면 새로 생성되고, 이미 존재한다면 기존 내용이 덮어써질 수 있다.

### `-i` 옵션

```bash
cp -i file1 file2
```

대상 파일이 이미 존재하는 경우 덮어쓸 것인지 사용자에게 확인한다.

### 디렉토리 내부로 파일 복사

```bash
cp file1 dir1
```

`file1`을 `dir1` 디렉토리 내부로 복사한다.

### 디렉토리 복사

```bash
cp -R dir1 dir2
```

디렉토리 내부의 모든 내용을 포함하여 복사한다.

---

## 10. `mv`

`mv`는 파일이나 디렉토리를 이동하거나 이름을 변경할 때 사용한다.

### 이름 변경

```bash
mv file1 file2
```

`file1`의 이름을 `file2`로 변경할 수 있다.

단, `file2`가 이미 존재하면 기존 파일이 덮어써질 수 있다.

### `-i` 옵션

```bash
mv -i file1 file2
```

대상 파일이 이미 존재하면 덮어쓸 것인지 확인한다.

### 파일 이동

```bash
mv file1 file2 dir1
```

`file1`, `file2`를 `dir1` 디렉토리로 이동한다.

### 디렉토리 이동 또는 이름 변경

```bash
mv dir1 dir2
```

`dir2`가 존재하지 않으면 `dir1`의 이름이 `dir2`로 변경된다.

`dir2`가 이미 존재한다면 `dir1`이 `dir2` 내부로 이동한다.

---

## 11. `rm`

`rm`은 파일이나 디렉토리를 삭제하는 명령어이다.

```bash
rm file1
```

### `-i` 옵션

```bash
rm -i file1
```

파일을 삭제하기 전에 사용자에게 확인한다.

### 디렉토리 삭제

```bash
rm -r dir1
```

디렉토리와 그 내부의 파일들을 함께 삭제한다.

> `rm`으로 삭제한 파일과 디렉토리는 영구적으로 삭제될 수 있으므로 특히 주의해야 한다.

---

## 12. `mkdir`

`mkdir`은 새로운 디렉토리를 생성하는 명령어이다.

```bash
mkdir directory_name
```

예시:

```bash
mkdir asset
```

`asset`이라는 새로운 디렉토리가 생성된다.

---

# Wildcards

## 13. Wildcard

Wildcard를 사용하면 여러 파일을 특정 패턴으로 한 번에 선택할 수 있다.

### `*`

```bash
*
```

모든 파일 이름과 일치한다.

예:

```bash
g*
```

`g`로 시작하는 모든 파일과 일치한다.

```bash
b*.txt
```

`b`로 시작하고 `.txt`로 끝나는 모든 파일과 일치한다.

### `?`

`?`는 하나의 문자와 일치한다.

예:

```bash
Data???
```

`Data` 뒤에 정확히 3개의 문자가 있는 파일과 일치한다.

### Wildcard 사용 예시

```bash
cp *.txt text_files
```

현재 디렉토리의 모든 `.txt` 파일을 `text_files` 디렉토리로 복사한다.

```bash
rm *
```

현재 디렉토리의 모든 파일을 삭제할 수 있으므로 매우 주의해야 한다.

특히 `rm`과 Wildcard를 함께 사용할 때는 먼저 `ls`를 이용하여 어떤 파일이 선택되는지 확인한 후 사용하는 것이 안전하다.

# Help Commands

## 14. `help`

Shell의 built-in command에 대한 도움말을 확인할 수 있다.

```bash
help command
```

예시:

```bash
help cd
```

`cd` 명령어의 사용법과 옵션을 확인할 수 있다.

---

## 15. `man`

명령어의 manual을 확인할 수 있다.

```bash
man command
```

예시:

```bash
man cp
```

`cp` 명령어의 사용법, 옵션, 설명 등을 자세하게 확인할 수 있다.

---

## 16. `exit`

현재 실행 중인 Terminal 또는 Shell을 종료할 때 사용한다.

```bash
exit
```

# Summary

| Command | 기능                                 |
| ------- | ------------------------------------ |
| `pwd`   | 현재 디렉토리 경로 확인              |
| `ls`    | 파일 및 디렉토리 목록 확인           |
| `cd`    | 디렉토리 이동                        |
| `clear` | 터미널 화면 정리                     |
| `cp`    | 파일 및 디렉토리 복사                |
| `mv`    | 파일 및 디렉토리 이동 또는 이름 변경 |
| `rm`    | 파일 및 디렉토리 삭제                |
| `mkdir` | 새로운 디렉토리 생성                 |
| `help`  | Shell built-in command 도움말 확인   |
| `man`   | 명령어 manual 확인                   |
| `exit`  | Shell 종료                           |

추가로 Shell을 사용할 때는 다음 기능을 기억하면 편리하다.

- `Tab` : 자동완성
- `↑` : 이전 명령어 불러오기
- `.` : 현재 디렉토리
- `..` : 상위 디렉토리
- `~` : Home directory
- `*`, `?` : Wildcard

특히 `cp`, `mv`, `rm`과 같은 명령어는 파일을 덮어쓰거나 삭제할 수 있기 때문에 사용 시 주의해야 한다.
